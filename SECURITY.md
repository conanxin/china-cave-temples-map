# Security

## Secrets

Never commit real values for:

- `VITE_AMAP_KEY`
- `VITE_AMAP_SECURITY_CODE`
- GitHub, Vercel, Cloudflare, or other access tokens

Use local `.env.local` files or deployment-platform environment variables.

## Reporting

For security-sensitive issues, contact the repository owner privately rather than opening a public issue containing credentials or exploit details.
