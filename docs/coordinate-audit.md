## v0.5 空间语义纠错与响堂山拆分

本阶段优先修正“一个国保项目并不等于一个点”的空间语义，而不是追求父级完成率：

- **07 响堂山石窟**：河北省文物部门资料明确该国保项目由南响堂、北响堂和小响堂三处组成。原 v0.4 的父级点实际上只对应北响堂，因此 v0.5 将父级退回 `unresolved`，新增：
  - **07A 北响堂山石窟**（114.161145, 36.533757），高德 POI `B01360168L`；
  - **07B 南响堂山石窟**（114.196564, 36.426963），高德 POI `B0136016SY`；
  - **小响堂**继续待核验，不人为补一个坐标。
- **26 千佛崖造像**：济南市国土空间规划与山东省文物保护资料均表明该国保对象不是单一摩崖点，而包含千佛崖造像、龙虎塔、九顶塔等组成内容，已改为 `mixed + group`，组成点坐标继续逐一核验。
- **33 灵泉寺石窟**：现行行政区更新为安阳市 **龙安区善应镇**。河南省文物建筑保护研究院 2024 年资料记载现存龛窟 230 余座，分布于宝山、岚峰山、马鞍山；因此父级改为 `group`，后续按山体及大住圣窟、大留圣窟等代表窟拆分。

这一轮使父级 `verified` 从 36 降为 35，却把已核验组成点从 7 增到 9、默认 Marker 从 43 增到 44。数字下降并不是退步，而是删除了“北响堂代表整个响堂山”的伪精确表达。

## 为什么其余 73 个父级项目仍不直接画成“精确点”

项目的核心约束是不能把城市中心、县政府、山体中心、景区公交站或一次自动地理编码结果伪装成遗址本体坐标。部分遗址存在同名 POI、历史行政区变更、复合国保项目或多个洞窟群，因此必须逐项完成消歧后才能晋升为 `verified`。

其中有些父级项目虽然仍为 `unresolved`，但已经拥有可信的已核验组成点；这种情况下网页会显示字母后缀 Marker，而不会伪造父级中心点。

## 人工晋升 `verified` 的标准

1. 名称与国保正式名称能够消歧。
2. 县、乡、村或具体山体位置一致。
3. 高德底图 POI 与文物部门 / 遗址保护机构资料描述一致。
4. 大型遗址群明确区分父级项目与组成点；一个子点不得冒充完整保护范围。
5. 最终地图坐标使用 GCJ-02，并记录 `coordinateSource` / `source` 与 `verificationNote`。
