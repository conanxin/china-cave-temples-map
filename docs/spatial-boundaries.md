# 空间范围与保护边界方法

更新：2026-09-12 · v0.9

## 目的

项目不仅保存“点”，也保存范围证据与范围几何。范围几何比 Marker 更容易制造“看起来非常准确、实际上没有证据”的错觉，因此发布门槛高于点位。

数据结构见 `src/data/types.ts` 的 `SiteSpatialExtent` / `SpatialSourceAsset`，地图转换见 `src/map/getSpatialExtentPolygons.ts`，证据台账见 `docs/spatial-source-ledger.md`，源文件处理状态见 `docs/spatial-asset-registry.md`。

## 五种范围语义

### 1. `legal-protection`

国内法定文物保护范围。只有文物主管部门公布了可以可靠复原的坐标、矢量数据或清晰图纸，并完成坐标系核验后，才允许附带 Polygon / MultiPolygon。

仅有文字四至时保存为 `geometryStatus: 'text-only'`，详情可读但地图不画。

### 2. `construction-control`

国内建设控制地带，与法定保护范围分开建模。即使文字规定“向外延伸1500米”，如果基线保护范围自身没有可靠几何，也禁止自行做 buffer。

### 3. `published-site-extent`

学术调查、遗址介绍或其他公开资料给出的洞窟群经纬分布范围。用于研究型空间包络，并明确：

- 不是国保法定保护范围；
- 不一定等于洞窟实际连续分布轮廓；
- 如果来源只给经纬最大/最小值，只画可复算外接矩形，不沿地形主观描边。

### 4. `world-heritage-property`

UNESCO 世界遗产组成遗产的遗产区（property）。它与国内国保保护范围是两套制度语义，绝不能互相改名或替代。

仅有 UNESCO 公布面积与代表坐标时保存为 `text-only`；只有获取官方矢量/可可靠配准的官方地图后，才能发布边界几何。

### 5. `world-heritage-buffer`

UNESCO 世界遗产缓冲区（buffer zone），与遗产区单独建模。不能用面积、代表点或国内建设控制地带反推出它的几何。

## 来源与推导元数据

v0.8 起每条规范空间证据都要求保存：

- `evidenceTier`：官方一级 / 机构一级 / 公开二手；
- `derivation`：官方矢量 / 官方坐标 / 官方图纸配准 / 已发表边界 / 纯文字；
- `sourceDate`；
- `sourceUrl`；
- 如适用，`areaHa`、`sourceCrs`、`targetCrs`、`officialReference`。

目的不是增加字段，而是避免几年后无法回答“这个面从哪里来的”。

## v0.9：边界证据与源资产分离

从 v0.9 起，边界证据不再只依赖 `sourceUrl` 字符串。官方 PDF、地图集、GIS 页面、法规与案例均登记为 `SpatialSourceAsset`，并与具体 `SiteSpatialExtent.id` 建立显式关系。

这解决两个问题：

1. 同一份 UNESCO 地图集可以同时支撑 05 / 06 / 08 / 27 多个遗址的世界遗产范围证据；
2. “来源很权威”和“已经得到可绘制边界”不再混为一谈。UNESCO 官方地图 PDF 是 `official-primary`，但在没有提取、配准或矢量化之前，处理状态依然只是 `georeference-needed`。

因此，v0.9 对 05 麦积山与 27 大佛寺新增世界遗产 property / buffer 证据后，边界仍保持 `text-only`；官方代表坐标与面积都不能用来制造圆形、矩形或自动 buffer。


## v0.8 样板

### 06 炳灵寺

UNESCO 官方地图页提供 `1442-027` 的 WGS84 代表坐标、遗产区 132.62 ha、缓冲区 2,044.37 ha。代表坐标转换成 GCJ-02 后可作为遗址群定位点；面积不能反推边界，因此世界遗产两层继续 `text-only`。

甘肃省人大 2021 年保护条例确认国内保护范围分重点/一般区，范围由省政府划定公布，保护范围外可划建设控制地带；条例页面没有坐标表，因此国内法定层也保持 `text-only`。

### 08 克孜尔

UNESCO 官方代表坐标用于父级定位；新疆自治区政府 1999 年办法给出了保护范围和建设控制地带文字四至，但含“伊泻克沟洞窟、第一号洞窟、泪泉、雀尔塔格山北麓”等参照物。没有官方矢量前，不用卫星图手工猜线。

世界遗产遗产区 1,798.48 ha、缓冲区 9,849.17 ha 只作为官方面积证据记录。

### 09 库木吐喇

最高检典型案例证明2009年已有保护规划、“两线”跨县、2022年8月保护范围完成土地权属办理，但公开页面没有边界几何。因此法定保护范围和建设控制地带都是高可信 `text-only`，而不是低可信 Polygon。

### 26 千佛崖造像

山东省 2022 年正式文件提供千佛崖、九顶塔法定四至，并注明“具体范围以图纸为准”。继续只录文字，不根据景区院墙或 POI 自画多边形。

### 31 森木塞姆 / 46 克孜尔尕哈

当前可追溯范围来自二手公开汇编，经纬上下限逐角从 WGS84 转 GCJ-02 后形成研究外接矩形。它们是 `published-site-extent`，UI 明确标为公开二手来源，待一级资料替换。

## Polygon 发布门槛

一条范围只有同时满足以下条件才进入地图：

1. `geometryStatus === 'verified'`；
2. 存在 `geometry`；
3. Geometry 类型为 `Polygon` 或 `MultiPolygon`；
4. 外环至少四个点；
5. 坐标系统一到 GCJ-02；
6. 有来源 URL、来源等级、推导方法和语义说明；
7. 不以面积、单点或文字四至主观反推形状。

`getSpatialExtentPolygons()` 主动排除所有 `text-only` 记录。

## 地图视觉语义

- 法定保护范围：暗朱红，实线。
- 建设控制地带：土金色，虚线。
- 已发表遗址分布范围：蓝灰色，虚线。
- 世界遗产遗产区：深紫灰，实线。
- 世界遗产缓冲区：浅紫灰，虚线。
- 遗址群组成关系：灰褐色虚线，不属于空间范围图层。

## 下一步

优先获取：

1. 国家/地方文物主管部门 GIS、“一张图”或规划矢量附件；
2. UNESCO 官方组成遗产边界/缓冲区矢量；
3. 正式保护规划中的坐标表；
4. 有明确控制点的官方范围图，用于可复核配准；
5. 正式考古报告中的洞窟分区测绘。
