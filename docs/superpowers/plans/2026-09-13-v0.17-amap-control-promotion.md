# v0.17 高德控制点联动与人工晋升 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在配准工作台中加入高德现代底图控制点取点，并建立 human-approved canonical extent patch 的持久晋升链。

**Architecture:** georef 数学层继续使用 WGS84；AMap 点击的 GCJ-02 在进入 control point 前反算到 WGS84，同时保留原始点击 provenance。晋升结果先生成 draft patch，经明确确认后由独立脚本写入 reviewed patch registry；运行时再把 registry 合并到 canonical site extents。

**Tech Stack:** React, TypeScript, AMap JS API 2.0, Node built-in test runner, Python 3 unittest.

**Spec:** `docs/superpowers/specs/2026-09-13-v0.17-amap-control-promotion-design.md`

## Global Constraints

- 浏览器不直接修改 canonical registry。
- 已 verified extent 默认不允许被 patch 覆盖。
- AMap click 的原始坐标为 GCJ-02；配准 ground 坐标保持 WGS84。
- 所有 canonical patch 必须经过 `APPROVE <site-code> <extent-id>` 人工确认。
- Patch registry 只保存 `human-approved` patch。
